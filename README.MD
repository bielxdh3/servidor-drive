# ROOT.ark

O root.ark é uma solução moderna para o arquivamento e gestão de dados. Projetado com foco na experiência do usuário, ele permite não apenas organizar arquivos em estruturas de pastas inteligentes, mas também compartilhar conteúdo de forma segura através de links temporários.

## 📸 Preview

![preview do projeto](./public/assets/image.png)

## 💎 Diferenciais da Aplicação

📁 Estrutura de Pastas Dinâmica
Organize seus arquivos com uma hierarquia lógica. A interface permite criar, renomear e mover diretórios, mantendo o ambiente de trabalho limpo e intuitivo.

🔗 Links Temporários (TTL - Time to Live)
Segurança em primeiro lugar. Gere links de compartilhamento que expiram automaticamente.

- Controle total: Defina se o link expira em minutos, horas ou após um número específico de acessos.

- Privacidade: Ideal para envio de documentos sensíveis que não devem ficar permanentemente públicos.

## 🎨 Interface Ultra-Moderna
Construída com foco em Clean Design, utilizando:

Dark Mode Nativo: Conforto visual para longas jornadas de trabalho.

Micro-interações: Feedback visual imediato ao arrastar arquivos ou criar pastas.

## 🛠️ Stack Técnica
Front-end: JavaScript (ES6+), HTML5 Semântico e CSS moderno (Flexbox/Grid).

Gerenciamento de Tempo: DayJS para controle preciso da expiração dos links.

Bundler: Webpack para um build otimizado e rápido.

Persistência: API REST integrada para manipulação de metadados das pastas e arquivos.
